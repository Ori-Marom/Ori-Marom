## Selected projects

### [LatentSpace Explorer](https://github.com/Ori-Marom/LatentSpace-Explorer)

**Word embeddings, made explorable.**

An interactive Java application for exploring word embeddings in 2D and 3D. Combines a Swing/JavaFX interface with a Python PCA pipeline, word search, similarity metrics, and vector arithmetic.

`Java` `Swing` `JavaFX` `Python` `PCA` `Design Patterns`

[Explore the code →](https://github.com/Ori-Marom/LatentSpace-Explorer) · [Demo walkthrough →](https://github.com/Ori-Marom/LatentSpace-Explorer/blob/main/docs/DEMO.md)

### [StreamLink RUDP](https://github.com/Ori-Marom/streamlink-rudp)

**Exploring reliability on top of UDP.**

A Python networking prototype combining local service-discovery simulations, TCP downloads, and a custom reliable transport over UDP. Explores sliding windows, acknowledgements, retransmission, congestion control, and adaptive media-chunk delivery.

`Python` `Socket Programming` `TCP/UDP` `Congestion Control`

[Explore the code →](https://github.com/Ori-Marom/streamlink-rudp) · [Protocol design →](https://github.com/Ori-Marom/streamlink-rudp/blob/main/docs/PROTOCOL.md)
